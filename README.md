# Pathfinding Across Scales — From Cosmos to Quantum

🚀 **[Live Demo](https://kylemath.github.io/FlowFinding)** 🚀

An interactive educational web application that explores how systems find their paths across vastly different scales, from planetary orbits to quantum algorithms.

## Overview

This project takes users on a journey through pathfinding phenomena at multiple scales:

- **Cosmic Scale (10²⁶ m)** — Planetary orbits and gravitational dynamics
- **Earth Systems (10⁷ m)** — Atmospheric circulation, ocean currents, and tectonic flow
- **Surface Scale (10³ m)** — Lightning, rivers, trees, and ecosystems
- **Human Scale (10⁰ m)** — Human navigation and algorithmic pathfinding (Dijkstra, A*)
- **Molecular Scale (10⁻⁹ m)** — Protein folding, enzyme binding, cellular signaling
- **Quantum Scale (10⁻¹⁵ m)** — Quantum superposition, interference, and the double-slit experiment

The journey culminates in an exploration of the **HHL Algorithm** (Harrow-Hassidim-Lloyd), a quantum algorithm that solves linear systems exponentially faster than classical methods, and connects to the **GTTI Framework** (Homogenization Theory and Quantum Circuit Mapping).

## Features

- **Interactive Visualizations** — Canvas-based animations for each scale
- **Mathematical Explorations** — Interactive sliders to manipulate physical parameters
- **Tabbed Navigation** — Seamless navigation between different scales
- **Educational Content** — Clear explanations connecting pathfinding concepts across scales
- **GTTI Framework** — Advanced sections on homogenization theory, circuit mapping, and unified framework

## Getting Started

1. Clone or download the repository
2. Open `index.html` in a modern web browser
3. Navigate through the tabs to explore pathfinding at different scales

No build process or dependencies required — this is a pure HTML/CSS/JavaScript application.

## Key Concepts Explored

### Classical Pathfinding
- Gravitational geodesics and orbital mechanics
- Fluid dynamics and energy gradients
- Local rules producing global patterns (lightning branching, river networks)
- Algorithmic search (BFS, Dijkstra's, A*)

### Quantum Pathfinding
- Superposition — particles exist in all paths simultaneously
- Interference — amplitudes add constructively or destructively
- Feynman's path integral formulation
- The HHL algorithm for solving Ax = b

### GTTI Framework
- **Solvability Number (σ)** — Ratio of stress accumulation to capacity growth
- **Homogenization** — How discrete events blur into continuous dynamics
- **Aleph Events** — Topological interventions when σ → 1
- **Rigidity Death** — System limits when the spectral gap closes
